# ecore 芯片外贸 CRM

面向 ecore 海外企业级服务器器件采购与双向业务开发的轻量 CRM。系统以“合格账户 → 正确联系人 → 建立联系 → 需求/库存发现 → 资料齐全 → 商务评估 → 核验 → 成交”为主漏斗，并包含 A/B/C 账户评级、Buy-from / Sell-to / Two-way 方向、库存资料完整度、内部决策队列、跟进任务、触达记录、老板周报，以及加密备份/恢复。

库存核验覆盖 Exact PN、数量、Condition、包装封签、库存地点、货权、可用时间、价格、Date Code、COO、图片/视频、可追溯性、Warranty/RMA、交期和 Incoterm。旧版浏览器数据会在解锁后自动兼容到新版结构。

## 研究名单增量导入

2026-08-13 版本内置 40 家经 AMD EPYC 官方方案商目录与公司官网交叉核验的服务器、HPC/AI 和存储集成商。已有浏览器数据会在解锁时进行去重合并，不覆盖用户已经录入的联系人、进度、备注或报价；其中 12 家优先账户会自动生成分批首触达任务。

## 数据安全

GitHub Pages 只托管网页程序。客户、联系人、报价与跟进数据使用用户设置的密码加密后，保存在当前浏览器的 `localStorage` 中，不会提交到 GitHub 仓库。

请定期使用系统左侧的“下载加密备份”。换电脑或清除浏览器数据前，务必先下载备份。

## 使用方式

访问 GitHub Pages 地址，首次使用时设置至少 6 位的本机访问密码。后续使用同一浏览器时输入该密码即可解锁。
